# Challenge-7

What's your taste application:


## Description

* As a developer, I want to create a command-line application that takes input from the end user and logs a message with a user’s favorite color and food to the console. The motivation for this application to get to know a little more about the user learning their  taste in color and their favorite kind of food.

## Project guidelines 

This was done when I initialized my repository with a `package.json` file by running `npm init -y`.

* It's done when I set the `"type"` property to `"module"` in my `package.json` to allow for ESM style imports.

* It's done when I have installed `inquirer` added it to my list of dependencies by running `npm i inquirer`.

* It's done when I have installed `colors` and added it to my list of dependencies by running `npm i colors`.

* It's done when the application asks the user, "What text would you like to log?".

* It's done when the application asks the user, "What color would you like to use?", and has the options "red", "blue", "green", "yellow", "cyan", and "magenta".

* It is done when the application asks the user, "What your favorite kind of food", and has these options to choose from "Italian", "Chinese", "American", "Soul", "Mexican", "Indian".

## Motivation to why built this project

**I built this project for the motivation of learning more about the user taste in color to see if have similar taste to the user and in the future to be able to gather data towards survey shows for ex. 30 % more of people like red versus the color yellow…
